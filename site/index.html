XLG

Express more in one line

fetch "api.example.com/users" | parse json | store "users.db"

Use Cases

API to Database

fetch "api/users" | parse json | get "data" | store "users.db"

CSV Processing

read "sales.csv" | parse csv | filter "region" "west" | print

Data Pipeline

fetch "api/metrics" | parse json | sort "timestamp" | take 100 | write "latest.json"

Python vs XLG

Python (20+ lines)
# imports, request, error handling,
# json parsing, db connection,
# table creation, insert loop,
# commit, close...
XLG (1 line)
fetch "url" | parse json | store "data.db"
